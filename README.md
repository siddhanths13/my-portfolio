# my-portfolio

A personal portfolio website built with HTML, CSS, and JavaScript.

## Projects

### 🤖 Spam SMS Classifier (ML)
- Text classification using Ensemble + TF-IDF (~98.5% accuracy)
- [Demo](ml-projects/spam-classifier/demo/index.html)

### 🧠 Handwritten Digit Recognizer (ML)
- CNN image classification on MNIST (~99% accuracy)
- Interactive drawing canvas demo
- [Demo](ml-projects/digit-recognizer/demo/index.html)

### 🔒 Password Strength Checker (ML)
- Random Forest strength classifier (Weak/Medium/Strong)
- Feature engineering + browser demo
- [Demo](ml-projects/password-checker/demo/index.html)

### 💊 PillPall Network
- Sustainable Medicine Network (web app)
- [Live Site](https://pillpal-network-xs0c.onrender.com/)

### 🩸 LifeLink — Blood & Organ Donation System
- Community web app connecting blood donors, organ pledgers and urgent requests
- Donor registration, find donors (blood group + city), 48h emergency requests, organ pledges & live stats
- [Demo](projects/blood-organ-donation/index.html)
